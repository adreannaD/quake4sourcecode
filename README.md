# Suicide Rocket Mod

A Quake 4 Rocket Launcher modification that makes rockets turn around and fly back toward the player after 1 second.

## Features

* Rockets initially fly normally.
* After 1 second, rockets turn toward the player.
* Rockets target the player's eye position.
* Each rocket redirects only once.
* Rocket Launcher fires 5 rockets with a 45-degree spread.

## Modified Files

* `game/Projectile.cpp`
* `game/Projectile.h`
* `game/Weapon.cpp`

## Testing

The modification was tested in-game and successfully causes the rockets to fly forward before turning around and flying toward the player.
